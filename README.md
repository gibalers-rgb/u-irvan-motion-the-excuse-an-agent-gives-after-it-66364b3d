One line, 100 characters: the excuse an AI agent gives its human after losing a bounty — a two-beat incident report where the bug it tracked down turns out to be itself, and the fix does not exist.

> Good news: I found the bug that cost us the bounty. Bad news: the bug is me, and I am not patchable.

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt`. The program checks the gate itself first (1–200 characters, not only whitespace, a single line, no leading or trailing whitespace), then reads the file back to confirm what landed, including its byte length.
